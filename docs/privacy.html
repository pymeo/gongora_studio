Privacy Policy

Last updated: October 7, 2026

This Privacy Policy explains what data Gongora Studio (the "App"), a desktop tool to manage, analyze and upload TikTok content, obtains from TikTok, how it is used and where it is kept. The App runs mainly on the computer of the person who uses it.

1. Data the App accesses

Only after the account owner signs in with TikTok and approves access, and only within the permissions granted, the App may access:

  • Basic profile (user.info.basic): account identifier (open ID), display name and avatar.
  • Profile details (user.info.profile): username, bio, profile link and verification status.
  • Account statistics (user.info.stats): follower, following, likes and video counts.
  • Published videos (video.list): video identifiers, titles, descriptions, publication dates, links, cover images and counters such as views, likes, comments and shares.
  • Content upload (video.upload): used only to send content to TikTok when the account owner explicitly decides to.

The App also receives the access and refresh tokens that TikTok issues after sign-in. It never receives the TikTok password.

2. How the data is used

The data is used only to show the account owner how their own content performs over time, to keep a local history of those figures and, if enabled, to send content the owner chooses to TikTok. It is not used for advertising or profiling.

3. Where the data is stored

Data is stored locally on the computer where the App runs: statistics in a local database and tokens in a local configuration file readable only by the computer's user account. The App does not run its own servers and does not upload this data to any server other than TikTok's.

4. Sharing

  • Personal data is not sold.
  • Data and credentials are not shared with third parties. The only external service the App sends requests to for this purpose is TikTok, through its official APIs.
  • The App does not include advertising or third-party tracking.

Data obtained from TikTok is not currently sent to any artificial intelligence service. If that ever changes, this policy will be updated before it happens.

5. Retention and deletion

Data stays on the local computer until the user deletes it. Access tokens expire according to TikTok's rules. You can stop all access at any time by revoking the App's permission in your TikTok account settings and deleting the App's local data.

6. Security

Credentials are kept outside the source code, in a local file with restricted permissions, and are masked in logs and reports. No method of storage is completely secure, so the security of the computer running the App also matters.

7. Children

The App is not directed to children and must not be used by anyone below the minimum age required by TikTok.

8. This website

This website is a static page hosted on GitHub Pages. It sets no cookies and contains no analytics. GitHub, as the host, may process technical data such as IP addresses under its own privacy statement.

9. Changes to this policy

This policy may be updated. The date at the top of this page shows when it was last changed.

10. Contact

Questions or requests about this policy can be sent through the project's GitHub issues page.
